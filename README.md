# NetworkLabs

Computer networks lab assignments and study materials from my university courses. This repository contains hands-on labs covering network configuration, routing, switching and troubleshooting.

## Repository Structure

| Folder | Description |
|--------|-------------|
| `AR` | Lab assignments for the *AR* course |
| `CCNA1-SAVNET` | CCNA 1 labs and exercises (Cisco Networking Academy) |
| `SCRC` | Lab assignments for the *SCRC* course |
| `MaterialLicenta` | Study materials for the bachelor's thesis |

## Topics Covered

- Basic router and switch configuration
- VLANs and trunking
- Static and dynamic routing
- NAT and DHCP
- Access Control Lists (ACLs)
- Network troubleshooting

## Tools

- Cisco Packet Tracer
- Cisco IOS CLI
